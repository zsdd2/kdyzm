# 3.1.51 · 派送员手机号提取修复

App 3.1.51/30151 修复“物流正文已有手机号，但订单基本信息未提供”的问题，支持圆通“姓名（号码）正在为您派件”和顺丰“快件交给联系人，正在派送”句式。保留明确派送员身份，排除网点、客服、揽收及收件人号码；签收服务提醒不清空已知号码，改派掩码、相同时刻冲突和无日期冲突仍保留未知。

只读复盘后台全部88个已保存历史订单，38单保留39运单589轨迹。按淘宝、拼多多、京东分别标注和回归：有明确派送号码的25运单由旧规则23个提升为25个，其余14个无可靠派送号码保持留空。建立39条完整脱敏历史回归和独立边界样本；结果仅适用于这批文本，不代表未来所有订单准确率。本轮为规则优化，无模型微调或生产AI调用，未补采历史订单、修改原始数据。

后台3.1.51业务逻辑不变，仅镜像内置新App及更新清单；插件1.2.1无需更新。镜像 `ghcr.io/zsdd2/kdyzm:3.1.51` 或 `:latest` 提供 amd64/arm64。App原签名覆盖安装保留数据，已有本地轨迹会重新识别，不需清库、卸载、重绑或等待重采。

NAS由使用者手动升级，保留数据卷、密钥和配置。实体手机安装、真实拨号和未来平台文案未在本轮验收；nightly未运行。
