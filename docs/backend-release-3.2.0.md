# App / 后台 3.2.0

后台统一整理淘宝、拼多多、京东的物流状态、发货和到达时间证据、站点与柜位、派送员号码，以及异常重试和已有 AI 识别流程。手机负责短信收集、订单匹配、人工确认和显示，减少两端重复推断造成的分歧。

普通同步只传整理后的轻量订单；实体未变化时仅更新账号和任务摘要。物流详情展开时单独加载，旧回复不能覆盖新证据、人工站点修正或已确认收到的状态。扫描短信不等待平台采集；确认收到、物流详情和后台同步互不阻塞。后台保留每平台约15分钟、平台错开5分钟采集，普通访问超过30分钟才请求补采，手动刷新仍可主动采集。

京东等待揽收、京东与顺丰门口送达、门店卡位与具体柜号均使用统一规则。缺失或冲突的时间保持待核对，不使用采集时间补造业务时间。AI开关、自动应用设置和每日预算沿用已有配置。

本次为配套改版：先更新后台到3.2.0，再从后台App更新入口覆盖安装3.2.0 / 30200。镜像内置同版同签名APK、更新清单和SHA256SUMS，下载App不依赖手机访问GitHub。不承诺旧App与新后台混用；无需清库、卸载App或重新绑定。

后台首次打开已有数据库前保存独立数据库及已有服务配置备份；手机首次处理非空旧状态前保存原始数据备份。备份失败则停止修改，历史记录、人工决定和离线确认队列保留。生产备份在首次运行新版时生成；发布本身没有备份或更新NAS、真实手机。

NAS由用户拉取 `ghcr.io/zsdd2/kdyzm:3.2.0` 或 `latest`，保留原数据卷、配置和加密密钥。具体备份与恢复步骤见 `docs/backend-order-authority-upgrade.md`。

验证覆盖App与后台回归、Android测试和lint、H5与APK资源一致性、浏览器连续确认和延迟详情、原签名及匿名下载，并核对amd64/arm64镜像实际内置更新文件。最终发布结果以对应Release、流水线和发布核验为准。实体手机和生产升级效果、nightly安全扫描尚未验收。
