# 取件助手 3.2.2

手机同步时间与任务状态更新复用已提交订单投影，减少重复计算；授权、规则和账号归属变动仍完整校验。新增按同步关联编号的分段诊断，区分网络、数据库、核心计算和保存失败；最多16条脱敏失败摘要可在重启后补报。

修复Android较大本地状态超过数据库游标单行限制时读取失败；在原事务中直接读取完整文本，保留短信、离线操作及重启后的显示。匹配占用检查直接查询当前有效关联，单轮匹配复用订单和运单索引，避免每个候选反复遍历完整列表；旧周期、失效及被忽略来源仍不能占用新包裹。

淘宝明确收取快件的节点恢复为发货证据。到站时间与站点身份分开验证，未确认别名保留候选并显示待核对；不同字母柜号、门栋、卡位和重新投递不能借旧时间。AI拒绝分类与离线样本评估帮助定位格式、证据及硬冲突问题，原有开关和预算不变。

淘宝分页覆盖与每日增量审计分别报告缺口。审计保存值与有效投影分开，完成采集不等于字段正确，包裹退出未收列表不等于问题修复。

先更新现有后台服务并保留原数据目录、Compose配置及密钥，然后覆盖安装配套App；不要卸载或清除数据。已有3.2.1客户端仍可同步，新增诊断与轻量导入需要App3.2.2。只改后台不能证明实体手机卡顿已解决，实体手机与新增真实未收包裹的效果需升级后继续观察。
