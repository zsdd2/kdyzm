# 取件助手后台 3.2.1

本版配套 App 3.2.1 / 30201，插件继续使用现有版本。

- 淘宝各分包独立整理物流轨迹和取件码，去重后按实际时间排序。明确的“柜号＋取件码”拆分为位置与有效取件码，避免客户端校验失败。
- 缺少年份的实际轨迹优先沿用该订单的年份；详情日期优先，其次列表日期，再参考本包裹完整日期，最后使用该次采集的年份。12 月 20—31 日与次年 1 月按跨年处理，不逐年搜索。完整日期原样保留，冲突、未来、非法日期、预计及缺乏完整证据的领取签收节点继续待核对。
- 三平台分别提取取件码，客户端优先核对有效取件码；同码但站点、运单或时间等证据冲突时保留待核对，并进入既有三轮重采与 AI 辅助流程。重码、多件、已领取记录保留既有保护。
- 新增手机与后台的自动脱敏交互诊断，可用现有独立只读凭据通过 `/v1/diagnostics/interactions` 查看同步请求、导入、耗时和回执。仅记录固定类别和数值，内存有限保留，重启清空；不记录短信、取件码、运单、手机号或凭据。

先更新后台镜像到 `ghcr.io/zsdd2/kdyzm:3.2.1`（或 `latest`），保留现有数据卷和配置，再覆盖安装 App 3.2.1。现有备份机制继续生效，勿先卸载 App 或清除数据。本次发布不操作 NAS。

真实双分包数据只做本地离线回放，用户升级前不能据此确认真实手机同步已通过；预计到达时间仍不会当成实际到站时间。
