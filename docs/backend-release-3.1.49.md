# App / 后台 3.1.49：送门口待确认与识别追踪修复

京东、顺丰送到门口后，待取件列表直接显示待确认包裹，支持逐件“确认收到”。通知中心、大组件及包裹记录继续使用同一份状态；不生成虚假的取件码，也不将确认扩大到同订单其他包裹。

明确门口送达的物流事件时间作为到货时间，用户点击确认收到的时间作为签收时间。确认前保持待确认，确认后可撤销。旧缓存可根据已保存证据显示，下一次正常采集持久修正。此兼容涵盖京东及其他购物平台使用顺丰的运单；驿站、柜机、本人实际领取继续按原规则处理。预计、失败、退回、未知或矛盾时间不用于填补到货时间。

每日识别复盘发现：已确认合并的旧运单行仍会进入异常追踪，导致有效包裹已领取后旧任务仍重试或等待AI。本版在共享识别范围中排除历史别名，旧任务随正常调度退出；保留历史行、有效运单和人工领取决定，不调整AI开关或预算。
